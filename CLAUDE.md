# CLAUDE.md — n8n-nodes-genieacs

## Overview
n8n community node for GenieACS, providing TR-069 device management, provisioning, task scheduling, and fault monitoring operations within n8n workflows.

## Tech Stack
- TypeScript
- n8n community node SDK
- Vitest (test framework)
- Node.js (build via `package.json` scripts)

## Development
```bash
npm install
npm run build        # Compile TypeScript
npm run lint         # Lint source
npm test             # Run vitest suite

# Icon generation
node build-icons.cjs
```

## Architecture
- `nodes/GenieAcs/` — Node implementation (resources: Device, Task, Tag, Fault, Preset, Provision, File)
- `credentials/` — GenieACS API credential definition (URL + Basic Auth)
- `tests/` — Vitest test suite
- `docs/` — Documentation and images

## Key Rules
- Never hardcode GenieACS credentials; use n8n credential system
- Follow n8n community node conventions for resource/operation patterns
- Maintain test coverage (Codecov integrated)
